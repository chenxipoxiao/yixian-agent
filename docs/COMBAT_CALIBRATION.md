## 通过完整模拟发现并修正的问题

- 灵猫乱剑：固定旧引擎中2、3级每段攻击是1，当前客户端三档均为2；根据明确的开战手牌张数计算额外攻击次数，不使用引擎默认17张手牌。
- 禅心锻身与百家23062：开局体魄参数额外加1，然后执行一次体魄增加。不能因为百家配置的“非战斗”标签就跳过这一开局联动。
- 当前常规百家排位没有旧赛季天赋共鸣，按用户明确确认建立版本和模式限制；其他版本不自动套用。
- 慈念曲终局减伤在龙鳞上限、偶数减半、护命及保命之前处理。使用本次模拟实际产生的终局状态。

## 使用入口

`tools/simulate_full_battle.py` 接收明确的开战输入，输出完整战斗、逐行动回合轨迹和命元结算预览。输入含 `start`、`combat_context`、`seed`；同速时还需明确的 `first_player`。环境用于模拟的对手手牌张数不等于策略可见信息，不能直接作为对手观察输入。

```powershell
.venv\Scripts\python.exe -X utf8 tools/simulate_full_battle.py runs/stages/20261112T025401Z-s2-destiny-reductions/full-battle-example.json --out runs/new-battle-result.json
```

示例为软件场景，不是真人回放。实际训练来源核对可重跑：

```powershell
.venv\Scripts\python.exe -X utf8 tools/audit_full_battles.py --pilot runs/calibration/20261111T1616-longyao-train-pilot/evidence-rounds.jsonl --context runs/stages/20261112T025401Z-s2-destiny-reductions/combat-context.json --out runs/new-full-battle-audit.json
```

输出路径必须是新文件，历史结果不可覆盖。回合上限截断、未知机制、缺失手牌/镜像上下文不能产生有效胜负标签。结算预览不修改比赛命元，也不自动发放龙鳞升牌、保命奖励或后续资源；完整八人比赛仍需资源账本接续。
