# 当前版本三类卡牌与原生战斗引擎复用

2026-11-12：`full_battle_v5` 在固定 yisim 主引擎上增加云剑·灵海、浮云飘零步、霸王举鼎的三个等级，共9个运行时映射。没有另写战斗调度器，也没有修改 `external/yisim`；v1–v4 的源码、证据和历史结果保留。

主路径是：明确的开战快照 → 严格转换和版本检查 → yisim 完整战斗 → 根据模拟终局计算命元损失 → 与回放对照。独立的 `combat_*` 边界研究组件保留作证据和检查，不作为重写整个引擎的路线。优先复用已有实现，只有实际缺失或有证据不一致的部分才增加版本化适配。

## 本轮新增卡牌

| 卡牌 | 新增的卡牌自身逻辑 | 复用的原生逻辑 |
|---|---|---|
| 云剑·灵海 | 先攻击再加灵气和云海；连云时增加额外次数，同时增加累计云剑次数 | 攻击、灵气联动、云剑分类及出牌后计数 |
| 浮云飘零步 | 按实际被触发牌位判奇偶；奇数位先按缺血量拆分回血与防御，偶数位加身法 | 回血修正、防御联动、云海消耗、追击资格与调度 |
| 霸王举鼎 | 灵气、体魄、加攻依客户端顺序执行 | 灵气、体魄上限与溢出回血、加攻联动 |

浮云的转防使用回血前的拆分值。例如2级、加灵气后有5灵气、缺3血：名义回复22，调用回血3、转防19。禁疗或减少回血不会把未回复的部分再转成防御。已有回血触发增加生命上限时也不重新计算这次拆分。

云剑·灵海的额外次数需要同时增加当前连云计数和累计云剑计数；之后仍由原生出牌后流程增加通常的一次。浮云本身不是云剑，出牌后会由原生云海流程消耗一层云海并续连云。这里只支持已通过现有准入检查的仙命和模式，不放宽未知共鸣、额外百家或其他未解析状态。

数值固定本地 `001.0008.0005`，依据配置及实际执行 IL。新版 wiki 可辅助定位卡牌，但不能直接用较新补丁数值核对旧回放。运行时别名不进入训练词表，也不代表官方卡牌 ID。
