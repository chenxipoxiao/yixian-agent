# 逍遥与双生三项效果的单场校准

固定规则版本 `001.0008.0005`、普通排位模式 3、百家之道内部赛季 10。入口为 `tools/simulate_full_battle_v53_safe.py`，结算继续采用 v47。v52r2 及更早的源码、契约、实验和结果均保留。v53 的第二候选只修正软件测试的场景计数，生产规则和引擎版本没有变化。

本批一起实现逍遥刻纹 5001、逍遥神力掌 5008、双生刻纹 5009，依据固定客户端的实际读取点和执行顺序，而不只依据文字描述。

- 逍遥刻纹：实际使用的牌须位于选定格、非隐藏、卡表 `level == 1`，且不是临时牌，才添加本次追击请求。卡表的 level 是境界字段，不等同于卡牌升级档位；满升级档位的练气牌仍可能符合。重复牌效中可重复请求，但追击次数仍由原调度器统一限制。
- 逍遥神力掌：开局存入 3 点待用加攻。第一次实际普通攻击在牌效前获得加攻，然后移除一次性标记并将这张实际牌标为消耗；以后不会重新装填。普通攻击 3/6/9 三档均核对。与已有普通攻击效果并存时，执行顺序为逍遥身法、神力掌、点穴手。
- 双生刻纹：选定格的当前实际牌须非隐藏、卡表 `level <= 2`。原牌执行后额外执行一次包含前触发、牌效、后触发的 `ExecuteEffect`；不重新付费，不再执行 `Execute` 前段的升降级，也不会递归触发双生自身。消耗牌仍完成本次额外牌效，普通重复来源与双生各加一次，不能相乘。

格位只取已经保存的准备期 `privateData.xianMoData.tempDatas` 投影，来源哈希和玩家位置逐一核对。明确存在的整张表缺少所选效果键时，遵循客户端 `GetFuMoGrid` 返回 0；整份投影缺失则保持未决。本批投影 10 份，未读取新的原始回放、保留测试或未来轮次，也未重放取得奖励。该环境输入不得直接作为对手策略的可见信息。

双生与主动的后续 280 重复效果并存时，原参考引擎内部顺序与客户端不同，当前明确阻断。待用消耗效果遇到无法确认实际牌身份的临时普通攻击，也保持未决。变牌后的身份不能唯一解析、重复期间牌身份改变等情况不生成胜负或奖励标签。
