# 狸之力命元结算 v47

当前常规排位、百家机制10。按2026年11月13日用户明确答复：狸之力回复命元可以超过100；先将回复计入命元，再判断云之庇护、金蝉脱壳等战后保命。来源保存在data/inspection/user-civet-settlement-2026-11-13.json。两条边界的来源是用户确认，不是服务器独立验收。

## 实现

沿用full_battle_v46的完整战斗和狸之力逐次执行记录，新增terminal_damage_v47及单场入口tools/simulate_full_battle_v47_safe.py。433/10433/20433每次非镜像回复3/6/9命元；结算前验证事件身份、镜像属性和累加总数，再加到开战命元。这里不按100封顶。之后沿用已有减伤、免伤与单个可用保命的计算顺序，保命使用回复后的余额。

例如14命元、狸之力回复3、本轮扣15：先变17，再扣到2，不消耗保命。12命元回复3后变15，扣15会致命，有可用保命时按原规则留1。99命元回复3，先到102；胜方也保留自己的命元回复。

`life_damage`继续表示战败扣除量，`civet_settlement.predicted_net_change`才是计入狸之力后的净变化。函数不修改传入状态，重复调用不会叠加回复；保命次数消耗及相关奖励仍作为待处理事件，不冒充完整八人局状态提交。直接扣命元与狸之力的战中交互、多个可用保命的优先级仍拒绝推测。
