# 天灵之音 v34

固定客户端001.0008.0005、普通模式3、百家机制10。可选v34接入1001“天灵之音”的准备阶段开关与按持有者执行的战斗开局；旧版本、S1/v3模型和原生yisim保持冻结。

## 已执行边界

持有者的普通仙命开局执行完毕后，若天灵之音开启，先使自己获得2灵气，再使对手获得2灵气；随后继续百家3001、灵植和卡牌先机。使用共享的获得灵气处理，不直接修改起始灵气，因此仍触发已实现的获得灵气联动。双方都持有时各自按顺序执行，不能在双方所有开局效果之前统一预加4灵气。

开关取自同份回放准备阶段privateData.xianMoData.tempDatas。明确存在的映射中1001值为0或缺少1001键，按客户端读取结果开启；有符号非零值关闭。缺少整个来源、映射或选择证据时拒绝执行，不补默认值。六条来源拥有1001的记录中，五条显式0、一条明确空映射；本轮只从此前缓存的来源投影提取该最小字段，并核对原始文件哈希，没有新解析档案。

该开关属于环境重建输入，不进入策略可见信息；没有据此完成对手开关预测或经营动作。卡牌取得、跨轮状态与其他尚未实现的百家仍由原检查阻断。证据由既有客户端IL读取点和固定配置支持，不通过回放战后血量反推输入。
