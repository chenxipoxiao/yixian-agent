# 完整战斗输入：后手计数的版本化处理

2026-11-12 在可选 v3 入口中处理永久字段10006“后手计数”。它保留在诊断元数据中，不复制为本场战斗增益，不决定本场先手，也不被重置或更新。原回放对象、v1/v2源码与行为保持原样。

依据为固定当前客户端的静态读取证据：扫描35510个可解析方法，未发生解析遗漏；10006的3处字面量用途均属于其他编号空间的库存或师徒功能。全部72处 `GetLastRoundPermanentBuffValue` 调用均使用明确常量，未读取10006。基础战斗构造器不批量复制永久表，初始化只单独处理体魄等明确字段，开局直接读取永久字典的分支也未含10006。

这支持当前版本单场战斗中的有界投影，不等于拿到了服务器实现。后手计数如何跨轮更新仍未实现。归元草10008、10009等有真实开局效果，仍然阻断；没有放开未知字段。输入限定版本001.0008.0005、模式3、百家机制10，且要求10006为明确的非负有界整数，缺失与0分别记录。
