同一组 **128 个训练来源整局、966 条开发战斗记录**，本机和服务器分别重新执行每一场可执行战斗与结算，没有读取保留测试集。无新增策略训练。

原有 868 条完整输出全部不变；新增 37 条执行，其中 33 条四项匹配。两台机器的完整结果规范化哈希均为 `7318121f39e1110293757937ef98adbbf0481307bd11f9bd47f5cc110b9ef7ca`。本机整场检查 451.38 秒，服务器 432.97 秒。

905 条中，173 条以原始记录随机结果作条件核对，726 条未触发运行时随机标记，另 6 条没有恢复原始随机序列。后者 4 条不匹配、2 条暂时匹配，全部不算随机机制校准通过。不能断言随机性是差异的唯一原因；没有搜索种子凑终局。79 条同速使用记录先手，单独保留条件限制。

每台机器的 4 项 Python 检查通过，其中包含覆盖全部 85 个新增 ID 的 63 个 Node 边界场景。前两次失败来自测试输入或预期错误，原脚本、失败输出与修正说明均保留，生产候选源码没有为通过测试而改写。这些软件场景不作为真实战斗校准数量。

现有开发集仅包含新增清单中的 19 个 ID，实际可执行开战状态启用了其中 17 个；其余 68 个尚缺此开发集的完整战斗覆盖。终局相同不唯一证明每个中间分支正确。`batch-coverage-v124.json` 分开记录拥有、启用、明确事件和终局证据。

3013 的开局状态转换未查明；已有明确生命及永久 17 的战斗消费者不能代替主动使用证据。7011/7038 的战后奖励暂不执行，单场准入分离仍需证据。已有 446/757、280/763 等卡牌交互限制继续保留。未恢复的字段不补零，终局和未来轮数据不作开战输入。
