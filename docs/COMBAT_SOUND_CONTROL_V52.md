# 三项声音效果的当前版本单场校准

固定规则版本 `001.0008.0005`、普通排位模式3、百家之道内部赛季10。新入口为 `tools/simulate_full_battle_v52r2_safe.py`，结算继续采用v47。旧入口、源码、实验及失败证据均保留。

本批一起接入回春之音1003、困仙之音1005、强化之音1007。开关只读取已存档的准备阶段数据：明确存在的开关表中，键缺省或值0表示启用，非0关闭；整份证据缺失则阻断。没有读取终局或未来轮次来补开战状态。

- 回春：同时记下双方当前生命的15%整数值，然后按拥有者、对手的顺序先加生命上限再回血。保留回血相关回调；不能改用最大生命，也不能先回满再取数。
- 困仙：双方各获得1层561。未获追击豁免时，在追击消耗前停止并清除315；保留豁免，不强行归零。每个持有者自己的回合末减少1层，双方都拥有时叠为2层，不能在一张牌或一次追击后减少。
- 强化：双方各获得1次281，遇到可升级牌时先消耗次数再升级。资格只检查卡表的`noUpgrade`，不检查隐藏标记或首次用格；普通攻击3/6/9三档可在该规则下变牌。满级牌保留次数，后续同格如果仍可升级，可以再次触发。

画龙刻纹13003仍独立执行自己的首次用格和隐藏牌限制；顺序为刻纹、281升级、后续降级。新增36条已可执行卡牌的变牌身份，用固定卡表核对，保持旧身份和旧效果不变。未实现的升级目标、歧义身份，以及尚有281时触发无法确认实际临时牌身份的嵌套执行，都返回未解决，不生成胜负标签。

证据为固定客户端IL、卡表及原有64个训练局的开发回放。完整报告、批次验证、剩余差异和本机/服务器哈希见 `runs/stages/latest.json` 指向的本轮阶段快照。批次合并后执行相关软件检查；新增准备上下文要求一次完整525条回归，因此没有额外重复一次同样大小的“局部测试”。

初版测试将隐藏的狂剑·炎舞误当成画龙刻纹可升级牌，预期多算一次升级；已保留失败测试和实验，换用非隐藏小还丹验证双升级，并单列隐藏牌场景。此失败发生在全量回放之前。后续修正版同时加入临时牌身份阻断。

这是单场开发校准，不能作为独立验收、当前版本离线强度或实战强度。S1牌序复现指标保持原义，S2未晋级，不启动战斗奖励训练。
