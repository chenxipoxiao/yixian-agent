## 已完成的7个小场景

- 波澜与五行印记：0气时聚气且不触发印记；2气时先付费再激活；原本已激活水灵时可以0气用牌。
- 同一火牌直接使用会触发周天剑阵；由五行流转临时调用时，不额外触发周天。
- 水势伤害不套用攻击增减益，但会扣防；云海续接非云剑时同步更新连云与累计使用数。
