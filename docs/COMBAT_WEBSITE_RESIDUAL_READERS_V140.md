新增读取证据：抱气法在客户端依次增加灵气、体魄、生命，与当前实现顺序一致；没有依据交换体魄与回血顺序来凑终局。崩拳·戳／弹均先攻击，再增加对应联动标记；弹的回血读取卡牌标注的正生命消耗。这些静态读取核对不等于真实中间行动日志。

网站卡牌目录提供ID、名称、等级和境界，没有提供卡牌的具体攻防数值；本报告的数值来自固定本地客户端。三条林小月差异属于同一份10月28日采集记录，另一条龙瑶记录采集于10月31日；本地规则快照为11月6日。日期先后只能提示需要核对版本，尚不能证明差异由版本造成。

牌阵、境界、修为和体魄均按网站权威战斗边界读取；额外生命上限仍来自最后一次开战前公开状态。网站没有直接记录开战HP、终局HP差和行动回合数，不能把这些模拟数值写成已验证观测，也不能用战后字段倒填。

另核对4条阵旗手牌缺口：全部需要对手的手牌，网站现有私有手牌属于录制者本人。不能把本人的手牌交给对手效果，也不能补为空表。此检查没有解除战斗阻断。
