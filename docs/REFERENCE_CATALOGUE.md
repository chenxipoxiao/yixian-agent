## 跳过百家之道

首次跳过转入该NPC配置对应的狻猊候选池。已经使用首次跳过后，再跳过普通百家邀约，按**本次邀约**的对应池结算：狻猊一档为3次换牌机会，二档为5次；不按第一次的档位锁定奖励，也不换算成抽牌或修为。

本地29个NPC配置的 `specialSkip` / `skipGotReplaceChance` 已与3/5规则一致核对。狻猊一池本地旧配置有11项，新图鉴有12项（新增金丹之道）；二池均为14项。当前图鉴不能直接覆盖旧回放的可选集合。

新增可选 `SeasonDecisionV2` 在显式提供的候选和换牌账户上结算重复跳过，尊重调用方提供的当前储存上限并记录溢出；同一次邀约不能重复领取。首次转入狻猊不同时发3/5D，仙命选择效果仍不由这个模块执行。它未接入 `run_match`，不生成候选、不恢复服务器操作、不宣称完整经营完成。若输入狻猊候选面板自身的跳过动作，会保留状态并拒绝猜测规则。
